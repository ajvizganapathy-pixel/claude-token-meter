Chrome / Edge 89+ required — Web Serial API
Before You Flash
  • Connect XIAO ESP32-S3 via USB-C.
  • Bootloader mode: hold BOOT → press RESET → release BOOT. No LED blink is normal.
  • Click Download Latest Firmware — fetches bootloader + partitions + firmware automatically.
  • Click Connect → select port → Flash All Parts. Device resets when done.
  • After reboot: connect to open WiFi ClaudeTokenMeter — captive portal opens for WiFi setup.

After Flashing
  • Device reboots → creates open WiFi AP: ClaudeTokenMeter (no password)
  • Connect phone/laptop to ClaudeTokenMeter → captive portal opens automatically (or go to 192.168.4.1)
  • Enter home WiFi SSID + password + optional API key + weekly limit → Save
  • Run companion: python companion/claude_monitor.py --discover
