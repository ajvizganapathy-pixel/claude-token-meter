  • Device reboots → open WiFi AP: ClaudeTokenMeter (no password)
  • Connect phone/laptop to ClaudeTokenMeter → captive portal opens (or go to 192.168.4.1)
  • Enter home WiFi credentials + optional API key + weekly token limit → Save
  • Run: python companion/claude_monitor.py --discover
