Before You Flash
  • Connect your XIAO ESP32-S3 via USB-C to your computer.
  • Enter bootloader mode: hold the BOOT button (B), press and release RESET (R), then release BOOT. The board will appear as a serial port — no LED blink is normal.
  • Select the firmware.bin file below (build it first with PlatformIO: pio run -t upload, then copy .pio/build/xiao_esp32s3/firmware.bin here), or use the pre-built release binary.
  • Click Connect, pick the serial port, then Flash. The board will reset automatically when done.

After Flashing
  • The device reboots and creates an open WiFi AP: ClaudeTokenMeter
  • Connect your phone/laptop to ClaudeTokenMeter (no password). A captive portal appears automatically — if not, open 192.168.4.1.
  • Enter your home WiFi credentials, optional Anthropic API key, and weekly token limit. Click Save.
  • The display shows the main dashboard. Run the companion script on your PC: python companion/claude_monitor.py --discover
